EKMIVO SMS FORWARDER — OWNER TESTS (MANUAL; NOT YET ACCEPTED)
================================================================
1. Payment Methods: create receiving bKash/Nagad/Rocket numbers you own. Verify
   full number/copy and tenant privacy.
2. SMS Devices: Connect phone, enter name, copy one-time pairing code.
   No parser, SMS source, subscription ID or account selection is required.
3. Android Home > Connect phone: consent, enter code, confirm; grant SMS.
   Expect ONE physical phone in website device list.
4. Android Refresh and Web Refresh: verify real heartbeat and permission state,
   never a fabricated payment-verified status.
5. Receive consented controlled payment SMS on two SIMs. Verify narrow scope:
   correct provider sender only and payment-like content, signed to Go.
6. With missing parser or unproven receiver, Go must durably store pending SMS
   but NOT verify payment. Provider SMS sender is NEVER actual payer.
7. On validated real receipt sample with full receiving identity, actual payer,
   original time and amount, uniquely match the correct intent and webhook once.
   Replay same SMS/event and verify no duplicate credit.
8. Send personal SMS, OTP, unrelated source and ambiguous receipt: no money paid.
   Unrelated texts must not be forwarded; unknown SIM must not map arbitrarily.
9. Offline: receive receipt, reboot, reconnect and retry; queue survives and
   empties only after durable ACK. Don't lose pending evidence on disconnect.
10. Change/disable receiving account while queued: capture version prevents
    reassignment; server retains diagnostic/pending evidence.
11. Deny/revoke SMS permission; inspect truthful status, then restore.
12. Revoke phone; verify signed API requests denied. Wrong workspace/realm/key
    also denied.
13. Checkout must display actual receiving number; no bypass of readiness gate.
14. Verify 320dp width, EN/BN, Light/Dark/System, accessible controls.
Record real device, APK/server SHA, time, redacted event/intent/webhook IDs,
parser version, pass/fail and exact blockers. NEVER call synthetic tests live.
